# MockSuite

Development repository for Mocksuite

## Prerequisites

- Java (17 or higher)

## Build Guide

### Building the Project

To build the project, run:

```bash
./gradlew build
```

Windows:

```bash
gradlew.bat build
```

### Start project

To run this project:
```bash
./gradlew run
```

Windows:
```bash
gradew.bat run
```

### Running Tests

To execute all tests:
```bash
./gradlew test
```

Windows:
```bash
gradlew.bat test
```

### Build JAR file

To create an executable JAR file:
```bash
./gradlew jar
```
The JAR file will be created in the build/libs/ directory.
